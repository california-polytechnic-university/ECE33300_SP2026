Connect‑8 is a hardware implementation of a Connect‑Four–style game built entirely in Verilog and deployed on the Nexys A7‑100T FPGA. It runs on an 8×8 grid, with players selecting columns using switches while the system handles gravity, turn tracking, win detection, and full game state updates. The design uses all major FPGA I/O: debounced switches, push buttons for undo/redo/reset, LEDs for turn and win indication, a multiplexed 7‑segment display for player and move count, UART for logging moves, and a full VGA graphics engine that renders the board in real time.

The system is fully modular, thoroughly tested, and validated through a comprehensive testbench with 65 passing assertions. The testbench uncovered a critical timing hazard that led to the addition of a COMMIT settle state, ensuring correct win detection. With clean architecture, multiple modeling styles, and reliable hardware behavior, Connect‑8 demonstrates a complete and polished FPGA game system that works flawlessly in simulation and on the physical board.
